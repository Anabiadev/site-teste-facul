        Backup e importação

        Os dados ficam guardados no navegador deste computador. Se alguém limpar os dados de navegação ou trocar de computador, eles somem. Por isso, faça um backup toda semana e guarde os arquivos no Google Drive.

        Fazer backup

        Baixa dois arquivos CSV (funcionários e ofícios) que também abrem no Excel. Se o navegador perguntar, permita baixar vários arquivos.

        Importar CSV

        Os registros importados são adicionados aos que já existem, e repetidos são ignorados. Datas podem estar no formato 31/12/2026. Use arquivos gerados pelo backup ou planilhas com os mesmos cabeçalhos.

        Cuidado

        Estas ações substituem ou apagam os dados que estão no sistema. Faça um backup antes.
